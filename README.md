## 🚀 How to Run

Since this is a client-side static web application, no complex installation or server setup is required.

### Method 1: Direct File Opening (Easiest)
1. Clone or download this repository to your local machine.
2. Navigate to the project folder.
3. Double-click on `index.html` to open it directly in your web browser.

### Method 2: Using VS Code Live Server (Recommended)
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension (by Daydey / Ritwick Dey).
3. Right-click on `index.html` and select **Open with Live Server**.
4. The website will automatically open in your default browser at `http://127.0.0.1:5500`.
